## Which file should I try first?

`CineBloom_1.4.1_SafeModernUI.jsx` is the newest recovered JSX file by version number. The files are preserved as recovered; this package does not imply that every version has been tested in your current After Effects environment.

## Upload to GitHub

1. Open your `CineBloom-` repository.
2. Select **Add file → Upload files**.
3. Extract this ZIP on your computer and upload the files inside the folder (including this README).
4. Commit the changes to `main`.

## Important recovery note

This package contains the CineBloom versions listed above. The later-mentioned v1.5.0 CEP UI ZIP was not present among the recovered files. The separate AE Agent / Codex project source has not yet been recovered, so it is not included here.
